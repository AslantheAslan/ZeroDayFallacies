
# ZeroDayFallacies: NN Pitfalls in Network Intrusion Detection

ZeroDayFallacies-NN-Pitfalls-in-Network-Intrusion-Detection is a research-driven project that explores the critical 
shortcomings of neural network-based approaches in detecting zero-day attacks within Network Intrusion Detection Systems
(NIDS). Despite the growing popularity of deep learning in cybersecurity, our findings highlight that many models demonstrate
poor generalization and overfit to known threats — leaving systems vulnerable to novel, unseen attacks.
